# Safe Steer

Safe Steer is a driver monitoring system developed using Python, Flask, OpenCV, MediaPipe, and SQLite.

## Features

* Driver drowsiness detection using Eye Aspect Ratio (EAR)
* Phone usage detection while driving
* Voice and sound alerts
* Incident logging system
* Driver dashboard
* Admin dashboard
* User authentication (Login and Signup)
* Simulated rescue call for unresponsive drivers

## Technologies Used

* Python
* Flask
* OpenCV
* MediaPipe
* SQLite
* Pygame
* Pyttsx3

## Project Objective

To improve road safety by monitoring driver behavior in real time and generating alerts when unsafe conditions are detected.
